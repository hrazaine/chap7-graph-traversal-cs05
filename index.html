    Topic 1 of 8

    Graph Terminology

    A graph G = (V, E) is a set of vertices V joined by a set of edges E. Pick a term to see it on the graph.

    UndirectedEdges have no direction. A–B is the same edge as B–A.
    DirectedEdges are arrows. A → B does not give you B → A.
    WeightedEach edge carries a cost such as distance, time or price.
    Tree and DAGA tree is connected with no cycles. A DAG is directed with no cycles.

    Topic 2 of 8

    Adjacency Matrix and Adjacency List

    Two ways to store the same graph. Hover or tap an edge, a 1 in the matrix, or an entry in the list to see where it lives in each view.

    Adjacency matrix

    M[i][j] = 1 when vertices i and j share an edge. The matrix is symmetric because the graph is undirected.

    Adjacency list

      Each vertex keeps only its actual neighbours.

      Topic 3 of 8

      Breadth-First Search — BFS

      Explore in layers: the start vertex, then everything one edge away, then two edges away, and so on. A queue keeps the order first in, first out.

      
          
        
            
      • A vertex is marked visited when it enters the queue, so nothing is queued twice.
        • 
            
      • On an unweighted graph it finds the fewest-edge path to every reachable vertex.
        • 
            
      • Runs in O(V + E) with an adjacency list.
        • 
          
      
        
      
        
      
      
      
    
      

    
    
      
      
      Topic 4 of 8
      
      
      Depth-First Search — DFS
      
      
      
        
      
          
      Go as deep as possible along one branch, then back up and try the next. The recursion call stack (or an explicit stack) remembers where to return.
      
          
      
          
        
            
      • Neighbours are tried in alphabetical order here, so the walk is repeatable.
        • 
            
      • Useful for cycle detection, topological sorting and finding connected components.
        • 
            
      • Runs in O(V + E) with an adjacency list.
        •

      Topic 6 of 8
      
      
      Dijkstra’s Shortest-Path Algorithm
      
      
      
        
      
          
      Finds the cheapest path from one source to every vertex in a graph with non-negative weights. Always finish the closest unfinished vertex next, then relax its edges.
      
          
      
          
        
            
      • Negative edge weights break the guarantee.
        • 
            
      • With a binary heap: O((V + E) log V).
        •

      Topic 8 of 8
      
      
      Kruskal’s Algorithm
      
      
      
        
      
          
      Sort the edges, then take them lightest first. Keep an edge only if it joins two different trees. Union-find answers that question quickly.
      
          
      
          
        
            
      • Sorting dominates: O(E log E), the same as O(E log V).
        • 
            
      • Stops as soon as V − 1 edges are chosen.
        •
